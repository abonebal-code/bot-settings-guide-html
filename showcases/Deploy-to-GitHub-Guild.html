Overview

What is GitDeploy?

ما هو GitDeploy؟

GitDeploy is a PowerShell script that automates the entire GitHub deployment workflow. Instead of running multiple git commands every time you make changes, you just double-click Deploy.bat and it handles everything — from checking your internet connection to opening your live site in the browser.

GitDeploy سكريبت PowerShell يؤتمت كامل عملية الرفع على GitHub. بدل تشغيل أوامر git يدوياً في كل مرة، فقط دبل كليك على Deploy.bat ويتكفل بكل شيء — من فحص الإنترنت حتى فتح موقعك في المتصفح.

It works with any project on your machine. You can reuse the same tool for all your projects — it asks for the project path each time (and remembers it).

يعمل مع أي مشروع على جهازك. يمكنك إعادة استخدام نفس الأداة لجميع مشاريعك — يطلب مسار المشروع ويتذكره.

Setup

First-time setup

الإعداد الأول

1
Open deploy.config.ps1
افتح deploy.config.ps1
Fill in your GitHub username and email address. This is the only file you ever need to edit.
أدخل اسم مستخدم GitHub وبريدك الإلكتروني. هذا الملف الوحيد الذي تحتاج تعديله.
deploy.config.ps1
$GIT_USER_NAME = "abonebal-code"
$GIT_USER_EMAIL = "your@email.com"
$GIT_BRANCH = "main"
2
Allow PowerShell scripts (one time only)
السماح بتشغيل سكريبتات PowerShell (مرة واحدة)
Open PowerShell as Administrator and run:
افتح PowerShell كـ Administrator وشغّل:
PS> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
3
Double-click Deploy.bat
دبل كليك على Deploy.bat
That's it. You're ready to deploy any project.
هذا كل شيء. أنت جاهز لنشر أي مشروع.

FAQ

Common questions

أسئلة شائعة

❓It says "not a git repository"يقول "not a git repository"
The script will initialize git automatically and ask for your GitHub URL. Paste the repo link and it continues.السكريبت سيهيئ git تلقائياً ويطلب رابط الريبو. الصق الرابط ويكمل.
❓Push failed / rejectedفشل الـ push
The script will ask if you want to force push. Type y to proceed.السكريبت سيسألك عن force push. اكتب y للمتابعة.
❓How to use with a different project?كيف أستخدمه مع مشروع آخر؟
Just run Deploy.bat again and enter the new project path. The script remembers it for next time.شغّل Deploy.bat مرة أخرى وأدخل مسار المشروع الجديد. يتذكره للمرة القادمة.
⚠️GitHub Pages not updating?الموقع لا يتحدث؟
Go to your repo → Settings → Pages → make sure Branch is set to main → Save.روح للريبو → Settings → Pages → تأكد أن Branch محدد على main → Save.
